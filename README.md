# 해외 진출 현황 지도

https://ksecret-inc.github.io/overseas-map/ — 노션 `/embed` 블록에 이 URL을 넣어 사용.

데이터는 구글시트 **해외영업팀 진출현황 › `지도_raw` 탭**을 페이지 로드 때마다 읽습니다.
시트 행을 추가·수정하면 지도에 바로 반영됩니다 (코드 수정 불필요).

| 열 | 내용 |
|---|---|
| A 국가 | 표시 이름 (한글) |
| B ISO3 | 국가 3자리 코드 (예: `JPN`) — 지도 매칭 키 |
| C 권역 | 유럽 / 아시아 / CIS / 미주 / 중동·아프리카 / 오세아니아 |
| D 상태 | 매출 발생 / 거래선 등록 / 제품 등록 중 / 협의 중 |
| E 비고 | 툴팁에 표시 |
| H1 | 기준일 |

시트는 "링크가 있는 모든 사용자 – 보기" 이상으로 공유되어 있어야 합니다.
